# History index

Purpose: Find selected decision traces outside default context.
Read when: A context file changes ownership, a decision is revisited, or a major phase starts.
Authority: Historical sources. Active approved guidance takes precedence.
Parent: [Context map](../README.md).
Retention: Topic, source, status and current owner for each useful trace.

No adopting-project decision traces are recorded.

When retaining a trace, record its source, decision, rationale, status and current owner.
Keep only information that helps explain a future choice or constraint.
Do not copy full transcripts or create one history entry for every PR.
Use the [history review triggers](../README.md#history-review-triggers) to select what to read.
